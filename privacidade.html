Política de Privacidade

Em vigor desde 2 de novembro de 2026.

O Youtube Automação é um programa pessoal, usado apenas pelo seu dono (Alex Araújo, alexjunioficial@gmail.com) para enviar vídeos aos próprios canais do YouTube. Esta política explica quais dados o app acessa e o que faz com eles.

Serviços de API do YouTube

O app usa os Serviços de API do YouTube (YouTube Data API v3). Ao autorizá-lo, você concorda com os Termos de Serviço do YouTube. Os dados também estão sujeitos à Política de Privacidade do Google.

Quais dados o app acessa

  • Permissão youtube.upload: enviar vídeos ao canal autorizado.
  • Permissão youtube.force-ssl: definir a miniatura e as legendas dos vídeos enviados e ler informações básicas do canal autorizado (nome e ID) para confirmar que o envio vai para o canal certo.

O app não lê comentários, mensagens, histórico, inscritos ou qualquer dado de outros usuários.

Como os dados são usados e guardados

  • O token de autorização fica guardado só no computador do dono do app, numa pasta local. Ele não é enviado a nenhum servidor além dos do próprio Google.
  • Os dados são usados apenas para enviar e configurar os vídeos dos canais do dono.
  • Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos.
  • O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Cookies

Este site e o app não usam cookies nem rastreamento.

Como revogar o acesso

Você pode remover o acesso do app a qualquer momento na página de permissões da Conta do Google. Para apagar o token guardado, basta excluir o arquivo de autorização do computador onde o app roda; os pedidos de exclusão também podem ser feitos pelo e-mail abaixo e são atendidos em até 7 dias.
